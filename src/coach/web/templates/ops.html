Ops

Everything coach does from the terminal. Long jobs run in the background — leave the page open to watch, or come back and re-check. Jobs live in this process only: restarting the server forgets their history.

Daily driver

Incremental WHOOP + MyFitnessPal (food + weight), then normalize. Sources that aren't configured skip cleanly instead of failing the run.

Backfill a window

For history the daily path missed. Leave dates empty to resume from the last ingest (WHOOP) or the past week (MFP).

Normalize

Re-derive canonical rows from raw. Rebuild re-derives everything — safe by design (raw is the source of truth and is never touched), but it takes longer.

Database

Backup writes a consistent snapshot. Verify runs an integrity check, row counts and the canonical fingerprint.

Evaluations

HRV is deterministic and free. Grounding calls the live model and burns API tokens (§8.7).
